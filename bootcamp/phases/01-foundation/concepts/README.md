# Phase 1 concept notes — EXEMPLARS

These are **filled examples**, not templates. They show what a good concept note
looks like after the DONE WHEN test has been passed.

**Read them AFTER you have written your own.** Reading an answer key first makes
your note imitate mine instead of recording what you actually learned — and a
note that records someone else's understanding is worth zero.

| File | Injected when |

| `multiple-comparisons.md` | Friday, Week 2 — when the 5th strategy's result needs a bar to be measured against |

Your own notes go in `notes/concepts/` in **your** repo, using
`shared/notes-templates/concept-note-template.md`.
